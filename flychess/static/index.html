    How this works

    The position is projected onto the fly's visual projection neurons: each piece type uses dedicated lobula columnar cell types, your pieces go to one eye and the fly's to the other, and each square is a retinotopic patch. The complete FlyWire v783 connectome then runs for 150 ms as a leaky integrate-and-fire network with the parameters of Shiu et al. 2024. A linear readout trained on Stockfish moves turns the resulting spike counts into a move. Nothing in the brain was changed; only the readout learned.
